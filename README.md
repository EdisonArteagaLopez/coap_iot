# CoAP IoT

Android app implementing the CoAP (Constrained Application Protocol) for lightweight IoT device communication.

## Features
- CoAP client/server communication
- IoT device discovery
- GET / POST / PUT / DELETE CoAP methods
- Lightweight protocol for constrained devices

## Requirements
- Android Studio
- Android SDK 21+
- IoT network access

## Installation
```bash
git clone git@github.com:EdisonArteagaLopez/coap_iot.git
```
Open in Android Studio → Build → Run
